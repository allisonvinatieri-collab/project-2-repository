This is the submitted Project 2 repository. A clean user starts with README.md: create a Python virtual environment, install requirements.txt, run the five standard-library tests, and start the Streamlit app with `streamlit run app.py`. The README also states the expected default result before the user runs anything: 70% BIL, 30% VT, 6.07% net annualized historical return, 4.54% annualized volatility, and 70% BIL.

The architecture has four layers. First, `Lab_15_prices.csv` is the fixed monthly-price input and `ALFRED_CPIAUCSL_vintages.csv` is the dated CPI monitoring input. Second, `Lab_15_portfolio.py` validates the price table, creates monthly returns, and estimates annualized arithmetic returns, volatility, and correlations. Third, `lowest_risk_mix` enumerates every long-only allocation in 5% steps that sums to 100%, discards a candidate if it misses the return objective or BIL floor, and retains the feasible candidate with the lowest volatility. Fourth, `app.py` passes the active controls to that engine and displays baselines, the constrained result, stresses, and the CPI availability gate.

The financial logic is intentional. Equal weight and inverse volatility are transparent baselines. The constrained search does not maximize return; it applies the return and reserve rules first, then minimizes volatility among the feasible candidates. Costs are explicit: the app converts the selected gross historical estimate into a net estimate by subtracting the displayed annual-cost assumption. CPI is not used to select weights because this project has no defensible causal model linking one CPI observation to allocation weights. It is instead a point-in-time monitoring control.

I will now run `python -m unittest discover -s tests -v`. The default known-answer test proves the headline allocation and metrics from the committed CSV. The VT-stress known-answer test protects the final-engine 65% BIL and 35% VT result after a one-point VT-return reduction. The suite also rejects an invalid reserve floor and proves that an observation published after 30 September 2026 is excluded from the CPI panel. All five tests pass.

The highest-risk claim is not that the app can display a portfolio; it is that a historical estimate is robust enough for a committee action. The last-36-month stress changes the selected mix by 20 percentage points, and the app therefore returns the process to committee review under its stated rule. The current limitation is that the committed price sample is short and does not include measured taxes, trading costs, liquidity constraints, or a forward-performance test. That is why the app is adoptable as a controlled workflow but the allocation is not approved for capital.
